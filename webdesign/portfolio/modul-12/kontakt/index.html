Häufige Fragen

Wird das Formular wirklich verschickt?

Nein. Das Formular ist ein Beispiel und führt nur auf eine Bestätigungsseite. Es wird nichts gespeichert oder versendet.

Warum funktioniert das Formular auch ohne JavaScript?

Die Regeln stehen im HTML (required, type, minlength). JavaScript verbessert nur die Meldungen.
