## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] Jede Seite hat eindeutigen `title`, `description` und Canonical
- [ ] `robots.txt` und `sitemap.xml` sind vorhanden und passen zusammen
- [ ] `noindex` steht nur auf den dafür vorgesehenen Seiten
- [ ] Open Graph, Favicons und Manifest sind eingebunden
- [ ] JSON-LD ist gültiges JSON
- [ ] `node tools/seo-check.js` meldet keine Probleme
- [ ] `docs/seo-audit.md` ist ausgefüllt
