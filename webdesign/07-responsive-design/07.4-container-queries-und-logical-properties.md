# 07.4 Container Queries und Logical Properties

> Modul 07 · Lehrplan 7.5 · Geschätzter Zeitaufwand: 60 Minuten

## Lernziele

- Du verwendest Container Queries für wiederverwendbare Komponenten.
- Du unterscheidest Container Queries von Media Queries.
- Du ersetzt physische Eigenschaften (`left`, `margin-top`) durch logische.

## Voraussetzungen

07.3

## Ausgangslage

Die Projektkarten stehen im Raster. Sie sollen sich nach ihrem eigenen Platz richten, nicht nach dem Fenster.

## Aufgabe

1. Öffne [`experimente/container-vs-media.html`](../portfolio/modul-07/experimente/container-vs-media.html). Variante A nutzt eine Media Query, Variante B eine Container Query. Was fällt in der schmalen Seitenleiste auf?
2. Erkläre: Welches Element braucht `container-type: inline-size`? Warum darf das Element mit der Container Query **nicht** selbst der Container sein?
3. Prüfe im Portfolio: `.karte--projekt` wechselt ab `30rem` Containerbreite in zwei Spalten. Warum bleibt die Karte bei 768 px Fensterbreite trotzdem untereinander?
4. Fülle die Tabelle: `margin-left`, `padding-top`, `border-right`, `width`, `top`, `text-align: left` als logische Eigenschaften.
5. Wann sind logische Eigenschaften wichtig (Sprachen von rechts nach links, vertikale Schrift)?

## Hinweise

- Container Queries brauchen einen Container-Vorfahren. Sie können nur Nachkommen stylen.
- `inline-size` ist die Breite in horizontaler Schrift. `cqi` ist 1 % der Containerbreite.
- Media Queries bleiben richtig für Seitenweites (Kopf, Seitenlayout, Druck, `prefers-*`).

---

## Lösung

1. In Variante A bekommt die Karte in der schmalen Seitenleiste ebenfalls das zweispaltige Layout, wenn das Fenster breit ist, und wird gequetscht. In B richtet sie sich nach ihrem Platz: Hauptspalte zweispaltig, Seitenleiste einspaltig.
2. Der Container ist der Wrapper (`.slot` bzw. `.karten-slot`). Die Karte darin wird gestylt. Ein Element kann sich nicht nach seiner eigenen Größe richten, weil das Layout daraus zirkulär würde.
3. Gemessen: Bei 768 px ist der Slot 356 px breit, also schmaler als `30rem` (480 px). Erst bei 1280 px Fensterbreite ist der Slot 500 px breit und die Abfrage greift: Die Karte hat dort zwei Spalten (`192px 258px`, Bild links).
4. | physisch | logisch |
   |---|---|
   | `margin-left` | `margin-inline-start` |
   | `padding-top` | `padding-block-start` |
   | `border-right` | `border-inline-end` |
   | `width` | `inline-size` |
   | `top` | `inset-block-start` |
   | `text-align: left` | `text-align: start` |
5. In Sprachen wie Arabisch oder Hebräisch (von rechts nach links) dreht sich `start` und `end` automatisch um. Du schreibst das CSS einmal.

## Erweiterungen

- Verwende die Einheit `cqi` für eine Überschrift, die mit der Kartenbreite skaliert.
