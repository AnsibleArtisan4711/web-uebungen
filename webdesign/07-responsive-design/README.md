## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] Alle Seiten haben die Viewport-Angabe
- [ ] Kein horizontales Scrollen bei 320, 360, 768 und 1280 px
- [ ] Die Projektkarten reagieren per Container Query auf ihren Platz
- [ ] Bilder haben aussagekräftiges `alt`, `width`, `height` und `srcset`
- [ ] Tippflächen sind mindestens 24 px, Navigation 44 px hoch
- [ ] `docs/geraetetest.md` ist ausgefüllt
