## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] Alle Seiten haben genau einen `main`, eine `h1` und lückenlose Überschriften
- [ ] Landmarken und Navigation mit `aria-current` sind umgesetzt, der Skip-Link funktioniert
- [ ] Sitemap und Content-Inventar liegen in `docs/`
- [ ] Jede Seite hat eigenen `title` und eigene `description`
- [ ] Validator ohne Fehler, Seite auch ohne CSS lesbar
