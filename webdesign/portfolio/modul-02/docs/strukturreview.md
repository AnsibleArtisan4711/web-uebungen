# Strukturreview Modul 02

| Prüfpunkt | Ergebnis |
|---|---|
| Genau ein `main`, eine `h1` je Seite, Überschriften lückenlos | ja |
| Landmarken vorhanden (`header`, `nav`, `main`, `footer`) | ja |
| Nur ein `nav`, daher einfaches `aria-label` | ja |
| Richtige Elemente (Listen, Links, Bilder mit `alt`) | ja |
| Keine Klick-Elemente als `div` | ja |
| Validator ohne Fehler (`html-validate`) | ja |
| Seite ohne CSS lesbar | zu prüfen (Styles in den DevTools abschalten) |
| Tab-Reihenfolge logisch (Skip-Link, Navigation, Inhalt) | zu prüfen mit Tab-Taste |
