# 08.1 User Needs

> Modul 08 · Lehrplan 8.2 · Geschätzter Zeitaufwand: 45 Minuten

## Lernziele

- Du unterscheidest Bedürfnisse (Ziele, Probleme) von Funktionswünschen.
- Du formulierst User Stories in der Form „Als … möchte ich …, damit …“.
- Du kennst Empathy Map und Jobs-to-be-done.

## Voraussetzungen

Modul 07 abgeschlossen

## Ausgangslage

Aus Modul 01 hast du Personas. Daraus werden jetzt Bedürfnisse und User Stories für das Portfolio.

## Aufgabe

1. Formuliere drei User Stories für einen Online-Shop in der Form „Als … möchte ich …, damit …“.
2. Formuliere für dein Portfolio fünf User Stories aus Sicht deiner Personas. Ergänze je ein prüfbares Akzeptanzkriterium.
3. Warum ist „Ich will ein Karussell auf der Startseite“ ein Funktionswunsch und kein Bedürfnis? Formuliere das dahinterliegende Bedürfnis.
4. Zeichne eine Empathy Map (denkt, fühlt, sagt, tut) für die Persona „Recruiterin“.
5. Nenne drei Wege, echte User Needs zu ermitteln. Welche Quelle hast du im Portfolio-Projekt **nicht**? Kennzeichne deine Annahmen als Annahmen.

## Hinweise

- Eine gute Story nennt das Warum („damit …“). Ohne diesen Teil wird sie zur Aufgabenliste.
- Ein Akzeptanzkriterium ist prüfbar: Du kannst mit Ja oder Nein antworten.
- Quellen: Interviews, Umfragen, Beobachtung, Support-Anfragen, Analytics, Suchbegriffe.

---

## Lösung

1. Beispiele: „Als Kundin möchte ich nach Größe filtern, damit ich nur passende Artikel sehe.“ „Als Käufer möchte ich als Gast bestellen, damit ich kein Konto anlegen muss.“ „Als Nutzer möchte ich Lieferkosten vor der Kasse sehen, damit es keine Überraschung gibt.“
2. Fertiger Stand: [`../portfolio/modul-08/docs/user-needs.md`](../portfolio/modul-08/docs/user-needs.md). Beispiel: „Als Recruiterin möchte ich den Lebenslauf in unter 30 Sekunden finden, damit ich entscheiden kann, ob ich weiterlese.“ Kriterium: Lebenslauf ist von jeder Seite mit einem Klick erreichbar.
3. Ein Karussell ist eine Lösung. Das Bedürfnis dahinter ist z. B. „Ich möchte schnell sehen, was es hier gibt.“ Dafür gibt es oft bessere Lösungen (klare Überschriften, Teaser).
4. Siehe Empathy Map in `user-needs.md`.
5. Interviews, Umfragen, Support-Anfragen, Analytics, Suchbegriffe. Im Portfolio-Projekt gibt es noch keine echten Nutzerdaten, alle Bedürfnisse sind Annahmen und stehen auch so im Dokument.

## Erweiterungen

- Befrage zwei Bekannte in 10 Minuten zu einer Bewerbungsseite und vergleiche mit deinen Annahmen.
