# 05.2 Typografie und Text Styling

> Modul 05 · Lehrplan 5.3 · Geschätzter Zeitaufwand: 75 Minuten

## Lernziele

- Du schreibst ein Typografie-Grundgerüst mit Schriftstack, `rem`-Basis, Zeilenhöhe und Textbreite.
- Du berechnest fluide Schriftgrößen mit `clamp()` und kennst die Grundlagen von Webfonts.

## Voraussetzungen

05.1

## Ausgangslage

Die Seite nutzt eine Systemschrift ohne durchdachte Größen.

## Aufgabe

1. Schreibe ein Typografie-Grundgerüst für `:root`, `body`, Überschriften und Absätze: Schriftstack mit Fallback, Basisgröße in `rem`, Zeilenhöhe einheitenlos (1,5 im Fließtext, 1,2 in Überschriften), Textbreite höchstens 65 `ch`.
2. Erzeuge eine **fluide Überschrift** zwischen 28 px (Viewport 320 px) und 48 px (Viewport 1280 px) mit `clamp()`. Rechne die Steigung und den Achsenabschnitt aus.
3. Warum darf die mittlere Komponente nicht nur aus `vw` bestehen? Welche WCAG-Regel wäre betroffen?
4. Setze `text-wrap: balance` für Überschriften, `text-wrap: pretty` für Absätze und `hyphens: auto`. Wovon hängt die Silbentrennung ab?
5. Lies [`docs/typografie.md`](../portfolio/modul-05/docs/typografie.md). Erkläre, wofür `font-display: swap` gut ist und welches Risiko es mitbringt. Warum sollen Webfonts selbst gehostet werden?

## Hinweise

- Rechenweg für `clamp(min, wert, max)`: Steigung = (48 − 28) ÷ (1280 − 320) = 0,02083 px je px = 2,083 vw. Achsenabschnitt = 28 − 0,02083 · 320 = 21,33 px = 1,333 rem.
- Das Lehrplan-Beispiel `clamp(1.75rem, 1.4rem + 1.5vw, 3rem)` erreicht 48 px erst bei etwa 1700 px Breite. Es ist weicher, aber nicht exakt auf 320/1280 px gerechnet.
- Webfont-Dateien liegen nicht im Repository (Lizenz, Größe). Die Vorlage steht in der Dokumentation.

---

## Lösung

1. ```css
:root {
  font-family: system-ui, -apple-system, "Segoe UI", sans-serif;
  line-height: 1.5;
}
body { font-size: 1rem; }
:is(h1, h2, h3) { line-height: 1.2; text-wrap: balance; }
p { max-width: 65ch; hyphens: auto; text-wrap: pretty; }
```
2. Exakt gerechnet: `font-size: clamp(1.75rem, 1.333rem + 2.083vw, 3rem);`. Probe: bei 320 px 21,33 + 6,67 = 28 px, bei 1280 px 21,33 + 26,67 = 48 px. Im Portfolio steht die weichere Variante `clamp(1.75rem, 1.4rem + 1.5vw, 3rem)`; gemessen: 28 px bei 320 px Breite und 41,6 px bei 1280 px.
3. Reine `vw`-Schrift reagiert nicht auf Browser-Zoom und die Schriftgrößeneinstellung. Das verletzt WCAG 1.4.4 (Textgröße ändern). Die `rem`-Komponente sorgt dafür, dass beides wirkt.
4. Silbentrennung braucht `lang="de"` am `html`-Element, damit der Browser das richtige Wörterbuch nimmt.
5. `font-display: swap` zeigt sofort eine Ersatzschrift und tauscht später. Das vermeidet unsichtbaren Text, kann aber beim Tausch Layoutverschiebungen (CLS) auslösen. Selbst gehostet: Performance (keine fremde Verbindung) und Datenschutz (keine IP-Übertragung an Dritte).
