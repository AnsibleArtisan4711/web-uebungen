# 11.3 Grid Lines und Platzierung

> Modul 11 · Lehrplan 11.4 · Geschätzter Zeitaufwand: 75 Minuten

## Lernziele

- Du platzierst Items über Linien (`grid-column`, `grid-row`) und mit `span`.
- Du nutzt negative Linien und benannte Linien.
- Du baust ein Layout, in dem Bilder die volle Breite haben und Text begrenzt ist.

## Voraussetzungen

11.2

## Ausgangslage

Items stehen bisher dort, wo der Browser sie hinsetzt. Jetzt bestimmst du ihre Position.

## Aufgabe

1. Wie viele Linien hat ein Grid mit 4 Spalten? Was bedeutet `-1`?
2. Platziere ein Element über alle Spalten eines 4-spaltigen Grids (zwei Schreibweisen), siehe [`experimente/lines.html`](../portfolio/modul-11/experimente/lines.html).
3. Was bewirken `grid-column: span 2` und `grid-column: 2 / span 2`?
4. Baue mit benannten Linien ein Layout: Bild über die volle Breite, Text zwischen `inhalt-start` und `inhalt-ende` mit höchstens 30rem.
5. Ein Seitenleisten-Element soll von Zeile 2 bis 4 reichen. Schreibe die Platzierung auf.

## Hinweise

- Ein Grid mit n Spalten hat n + 1 Linien. Negative Zahlen zählen von hinten.
- `span n` lässt die Startposition offen (Auto Placement) und legt nur die Breite fest.
- Benannte Linien machen das CSS lesbarer, vor allem für „Full Bleed“-Layouts.

---

## Lösung

1. 5 Linien (1 bis 5). `-1` ist die letzte Linie.
2. `grid-column: 1 / -1;` oder `grid-column: 1 / 5;` (bzw. `span 4`). Gemessen im Experiment: alle drei Varianten ergeben 968 px Breite, also über alle Spalten.
3. `span 2` = zwei Spalten breit, Startposition automatisch. `2 / span 2` = beginnt an Linie 2, zwei Spalten breit. Gemessen: Breite 480 px, Start bei x = 260 px (zweite Spalte).
4. ```css
.seite { display: grid; grid-template-columns: [voll-start] 1fr [inhalt-start] minmax(0, 30rem) [inhalt-ende] 1fr [voll-ende]; }
.bild { grid-column: voll-start / voll-ende; }
.text { grid-column: inhalt-start / inhalt-ende; }
```
   Gemessen: Bild so breit wie der Container (1000 px), Text 480 px (30rem) und mittig.
5. `grid-row: 2 / 4;` (bzw. `2 / span 2`). Ein Element von Zeile 2 bis 4 überspannt zwei Zeilen (zwischen Linie 2 und 4).

## Erweiterungen

- Platziere zwei Items bewusst in dieselbe Zelle (Überlappung) und steuere die Reihenfolge mit `z-index`.
