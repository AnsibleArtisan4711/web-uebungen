## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] User Stories mit Akzeptanzkriterien liegen vor (`docs/user-needs.md`)
- [ ] Drei User Flows sind als Mermaid gezeichnet und enthalten Fehlerfälle
- [ ] Wireframes für Start, Lebenslauf, Projekte und Blog existieren mobil und für Desktop
- [ ] Zustände von Formularfeldern und Listen sind getestet (`experimente/`)
- [ ] Heuristische Evaluation ist ausgefüllt, Befunde sind nachgeprüft
- [ ] Design-Review-Vorlage ist für die Wireframes ausgefüllt
