# 07.2 Media Queries und Breakpoints

> Modul 07 · Lehrplan 7.3 · Geschätzter Zeitaufwand: 60 Minuten

## Lernziele

- Du schreibst Media Queries mit `min-width` und `em`.
- Du legst Breakpoints nach dem Inhalt fest, nicht nach Gerätenamen.
- Du kennst Medienmerkmale wie `prefers-color-scheme`, `prefers-reduced-motion` und `print`.

## Voraussetzungen

07.1

## Ausgangslage

Das Portfolio-CSS enthält schon Media Queries. Du weißt noch nicht, warum sie bei 40em und 64em stehen.

## Aufgabe

1. Öffne [`experimente/media-queries.html`](../portfolio/modul-07/experimente/media-queries.html). Ergänze: ab `40em` zwei Spalten, ab `64em` drei Spalten. Verkleinere und vergrößere das Fenster.
2. Warum `em` statt `px` für Breakpoints? Teste: Stelle in den Browser-Einstellungen die Schriftgröße auf „sehr groß" und schaue, wann der Breakpoint auslöst.
3. Schreibe dieselbe Bedingung in der Range-Syntax (`width >= 40em`). Wann ist sie lesbarer?
4. Ziehe das Fenster langsam schmaler und notiere, bei welcher Breite **dein Portfolio** unschön wird (Zeilen zu lang, Navigation bricht). Das ist ein Breakpoint nach Inhalt.
5. Nenne drei Medienmerkmale außer `width`. Ergänze `@media print` so, dass die Navigation beim Drucken verschwindet.

## Hinweise

- Gerätebreiten ändern sich ständig. Der Inhalt zeigt dir, wann das Layout bricht.
- `em` in Media Queries bezieht sich immer auf die Standardschriftgröße des Browsers, nicht auf deine CSS-Angaben. Bei größerer Schrift wechselt das Layout deshalb früher.
- Mehrere Breakpoints sind kein Selbstzweck. Jeder zusätzliche kostet Wartung.

---

## Lösung

1. ```css
.raster { display: grid; gap: 1rem; grid-template-columns: 1fr; }
@media (min-width: 40em) { .raster { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 64em) { .raster { grid-template-columns: repeat(3, 1fr); } }
```
2. `em` skaliert mit der Schriftgröße der Nutzerin. Wer größere Schrift eingestellt hat, hat im Verhältnis weniger Platz, das Layout wechselt früher. Mit `px` bliebe es starr und der Text würde gequetscht.
3. ```css
@media (width >= 40em) { ... }
```
   Die Range-Syntax liest sich wie eine Ungleichung und ist bei Bereichen (`40em <= width < 64em`) deutlich klarer. Sie wird von allen aktuellen Browsern unterstützt. Für sehr alte Browser bleibt `min-width`.
4. Die Antwort hängt von deinem Stand ab. Im Portfolio ist ab 40em die Navigation einzeilig und der Kopf haftet, ab 64em ist der Inhalt auf `64rem` begrenzt.
5. Beispiele: `prefers-color-scheme`, `prefers-reduced-motion`, `hover`, `orientation`, `print`.
```css
@media print { .site-header, .nav, .site-footer { display: none; } }
```

## Erweiterungen

- Teste mit `@media (hover: hover)`, dass Hover-Effekte nur auf Geräten mit Maus angewendet werden.
