# Review-Übung

`aenderung.diff` ist ein Pull Request mit Absicht eingebauten Mängeln: eine „Hinweisbox“ mit CSS, HTML und JavaScript (29 neue Zeilen in drei Dateien). Aufgabe: Lies die Änderung wie eine Reviewerin (Checkliste: [`../review-checkliste.md`](../review-checkliste.md)), notiere deine Befunde mit „Vorschlag: … weil …“ und prüfe dann, was die automatischen Werkzeuge finden. Die Lösung steht in Übung 20.2.

Anwenden in einer Wegwerf-Kopie: `git apply docs/review-uebung/aenderung.diff` (im Ordner des Portfolios, nachdem es als Git-Repository initialisiert wurde, oder mit `patch -p1 < …`).
