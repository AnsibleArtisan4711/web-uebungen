# Rollen im Portfolio-Projekt

Im Einzelprojekt vereint eine Person alle Rollen. Der Rollenwechsel wird bewusst benannt, damit keine Aufgabe vergessen wird.

| Rolle | Aufgabe im Portfolio | Ergebnis | Wann aktiv |
|---|---|---|---|
| Projektleitung | Ziele, Zeitplan, Priorisierung, Abnahme | `projektplan.md` | laufend |
| UX-Research | Zielgruppen, Personas, Navigation | `personas.md` | Konzeption |
| UI-/Webdesign | Layout, Farben, Schrift | Wireframes, Styleguide | Design |
| Frontend | HTML, CSS, JavaScript | `index.html`, `css/main.css` | Umsetzung |
| Backend | entfällt (statische Seite) | nicht benötigt | - |
| Content/SEO | Texte, Bilder, Titel | Texte in den Seiten | Umsetzung |
| QA/Test | Browser, Geräte, Accessibility | Testprotokoll | Test |
| Betrieb | Hosting, Backup | Deployment-Notiz | Launch |
