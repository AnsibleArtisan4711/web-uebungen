# 03.3 Combinators

> Modul 03 · Lehrplan 3.4 · Geschätzter Zeitaufwand: 30 Minuten

## Lernziele

- Du kennst Nachfahren-, Kind-, Nachbar- und Geschwister-Kombinator.
- Du wählst Elemente nach ihrer Position im Baum aus.

## Voraussetzungen

03.2

## Ausgangslage

Die Navigation und die Karten haben Klassen, aber die Selektoren sind noch einzelne Namen.

## Aufgabe

1. Erkläre die Wirkung von `A B`, `A > B`, `A + B` und `A ~ B` in einem Satz.
2. Wähle in [`experimente/selektoren-uebung.html`](../portfolio/modul-03/experimente/selektoren-uebung.html): (a) alle Links in `nav`, (b) nur die direkten `li`-Kinder einer `ul`, (c) den Absatz, der direkt auf eine `h2` folgt.
3. Setze im Portfolio den Abstand zwischen den Kindern eines Containers mit `.stack > * + * {{ margin-top: 1rem; }}`. Warum entsteht kein überflüssiger Abstand vor dem ersten Kind?
4. Markiere in der Navigation den Link der aktuellen Seite über `.nav a[aria-current="page"]` (falls noch nicht geschehen).
5. Welcher Kombinator hat welche Spezifität?

## Hinweise

- Kombinatoren zählen in der Spezifität nichts. Nur die Selektoren dazwischen zählen.
- Der `.stack > * + *`-Trick („lobotomized owl“) setzt Abstand nur *zwischen* Geschwistern.

---

## Lösung

```css
nav a                 { }   /* Nachfahre */
ul > li               { }   /* direktes Kind */
h2 + p                { margin-top: 0; }   /* direkter Nachbar */
h2 ~ p                { }   /* alle folgenden Geschwister */
.stack > * + *        { margin-top: 1rem; }
```

1. `A B`: B irgendwo innerhalb von A. `A > B`: B ist direktes Kind von A. `A + B`: B folgt unmittelbar auf A. `A ~ B`: B folgt irgendwann auf A (gleiche Ebene).
3. `* + *` trifft nur Elemente, die einen Vorgänger haben. Das erste Kind hat keinen, also bekommt es keinen Abstand.
5. Keiner. Kombinatoren und `*` zählen 0.
