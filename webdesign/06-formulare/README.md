## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] Jedes Control hat ein Label mit `for` und `id`
- [ ] Das Kontaktformular nutzt passende Typen und `autocomplete`
- [ ] Radio-Gruppe steckt in `fieldset` mit `legend`
- [ ] Native Validierung funktioniert, `:user-invalid` zeigt Fehler erst nach Interaktion
- [ ] Der Fokus wird nicht vom haftenden Kopf verdeckt
- [ ] Die Seite `kontakt/danke/` bestätigt das Absenden
