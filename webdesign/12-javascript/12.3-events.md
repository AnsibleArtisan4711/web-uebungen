# 12.3 Events

> Modul 12 · Lehrplan 12.4 · Geschätzter Zeitaufwand: 75 Minuten

## Lernziele

- Du reagierst mit `addEventListener` auf Klick, Eingabe und Tastatur.
- Du nutzt Event-Delegation.
- Du baust ein zugängliches Menü mit `aria-expanded` und Escape.

## Voraussetzungen

12.2

## Ausgangslage

Das Menü ist auf kleinen Bildschirmen im Markup immer sichtbar. Es soll einklappen.

## Aufgabe

1. Teste bei 360 px Breite den Menü-Button: Er öffnet und schließt `.nav`. Welche Klasse schaltet `initMenue` um, und wo steht das CSS dazu?
2. Welche Tastaturbedienung funktioniert ohne zusätzlichen Code, und warum ist ein `<button>` besser als ein `<div>`?
3. Der Projektfilter hängt **einen** Listener an den Container der Chips, nicht einen pro Chip. Wie heißt das Muster, und welchen Vorteil hat es?
4. Escape soll das Menü schließen und den Fokus zurück auf den Button setzen. Warum der Fokus?
5. Was bewirken `preventDefault()` und `stopPropagation()`? Wann brauchst du sie?

## Hinweise

- `event.target.closest("button")` findet den Button, auch wenn auf ein Kind darin geklickt wurde.
- `aria-expanded` teilt Screenreadern den Zustand mit.
- Ab `40em` zeigt das CSS die Navigation immer und blendet den Button aus.

---

## Lösung

1. `nav--offen` wird auf `.nav` umgeschaltet. Das CSS steht in [`css/main.css`](../portfolio/modul-12/css/main.css): `.js .nav:not(.nav--offen) { display: none; }` (nur wenn JavaScript läuft), ab `40em` wird das aufgehoben. Gemessen bei 360 px: ohne Klick ist die Navigation unsichtbar, nach Klick sichtbar (`aria-expanded="true"`).
2. Ein `<button>` ist fokussierbar, hat Rolle und Name und reagiert auf Enter und Leertaste ohne Zusatzcode. Ein `<div>` müsste das alles nachbauen (`tabindex`, `role`, Tastaturhandler).
3. Event-Delegation. Ein Listener genügt, auch für Elemente, die später hinzukommen. Weniger Speicher, weniger Code.
4. Wer mit Tastatur oder Screenreader das Menü öffnet, verliert sonst die Orientierung, wenn das Menü verschwindet. Gemessen: Nach Escape ist `document.activeElement` der Menü-Button und `aria-expanded` wieder `false`.
5. `preventDefault()` verhindert die Standardaktion (Formular senden, Link folgen). `stopPropagation()` hält das Event im Baum auf, das brauchst du selten, weil es Delegation anderswo stört.

## Erweiterungen

- Schließe das Menü auch bei Klick außerhalb. Achte darauf, dass das keine neuen Tastaturprobleme erzeugt.
