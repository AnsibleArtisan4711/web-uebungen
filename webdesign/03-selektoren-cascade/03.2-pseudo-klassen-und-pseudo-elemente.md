# 03.2 Pseudo-Klassen und Pseudo-Elemente

> Modul 03 · Lehrplan 3.3 · Geschätzter Zeitaufwand: 60 Minuten

## Lernziele

- Du nutzt Pseudo-Klassen für Zustände und Positionen (`:hover`, `:focus-visible`, `:nth-child`, `:not`, `:is`, `:where`, `:has`).
- Du unterscheidest Pseudo-Klassen (ein Doppelpunkt) von Pseudo-Elementen (zwei Doppelpunkte).

## Voraussetzungen

03.1

## Ausgangslage

Links und Listen sind noch ungestaltet und reagieren nicht auf Zustände.

## Aufgabe

1. Gib Links einen sichtbaren Tastaturfokus mit `:focus-visible` (Rahmen mit 3 px) und eine Hover-Farbe. Warum ist `outline: none` ohne Ersatz ein Fehler?
2. Schreibe Selektoren für: (a) jede zweite Tabellenzeile, (b) ein Eingabefeld, das nach der Eingabe ungültig ist, (c) jedes dritte `li` ab dem ersten, (d) alle `li` außer dem letzten.
3. Gestalte die Kenntnisse-Liste im Lebenslauf als **Zebra-Muster** (`.kenntnisse > li:nth-child(odd)`).
4. Hänge mit `::after` an jeden externen Link einen Pfeil (`content: " \2197"`).
5. Erkläre den Unterschied zwischen `:is(h1, h2, h3) a` und `:where(h1, h2, h3) a`. Wann nimmst du welchen?
6. Schreibe einen Selektor mit `:has()`, der alle Karten auswählt, die einen Link enthalten.

## Hinweise

- `:has()` ist der „Elternselektor“ und ersetzt vieles, was früher JavaScript brauchte (Stand Nachrecherche: in allen großen Browsern verfügbar, vor dem Einsatz bei MDN/Baseline prüfen).
- `:user-invalid` greift erst nach Eingabe, `:invalid` sofort beim Laden.
- Pseudo-Elemente mit `content` erzeugen nur Dekoration. Wichtige Inhalte gehören in das HTML.

---

## Lösung

```css
a:hover          { color: #7a1f1f; }
a:focus-visible  { outline: 3px solid #1a73e8; outline-offset: 2px; }

tr:nth-child(even)       { background: #eef3fa; }
input:user-invalid       { border-color: crimson; }
li:nth-child(3n + 1)     { font-weight: 700; }
li:not(:last-child)      { margin-bottom: 0.25rem; }

.kenntnisse > li:nth-child(odd) { background: #eef3fa; }
a[href^="http"]::after   { content: " \2197"; }
.karte:has(a)            { border-color: #1a3c6e; }
```

1. Ohne `outline` sieht eine Person, die mit der Tastatur navigiert, nicht, wo sie sich befindet. Es ist ein Verstoß gegen Barrierefreiheit (Modul 14). `:focus-visible` zeigt den Rahmen nur bei Tastaturbedienung.
5. Beide wählen dieselben Elemente. `:is()` übernimmt die Spezifität des spezifischsten Arguments, `:where()` zählt immer 0. Für überschreibbare Basis-Styles nimmst du `:where()`, sonst `:is()`.
