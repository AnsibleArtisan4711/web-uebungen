# Sitemap und Navigationskonzept

```
Start (index.html)
  Lebenslauf        lebenslauf/
  Projekte          projekte/
  Blog              blog/
    Erster Beitrag  blog/erster-beitrag/
  Kontakt           kontakt/
```

- Fünf Hauptpunkte, flache Hierarchie (maximal zwei Ebenen)
- Wichtige Ziele (Lebenslauf, Projekte, Kontakt) stehen auf der obersten Ebene
- Sprechende URLs bilden die Hierarchie ab
- Aktuelle Seite wird mit `aria-current="page"` markiert
- Impressum und Datenschutz folgen in Modul 18 (Fußnavigation)
