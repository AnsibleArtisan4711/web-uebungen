# Webdesign-Kursreihe: HTML, CSS und responsives Design

Selbstlernkurs mit **einem durchgehenden Projekt**: Du baust Schritt für Schritt ein persönliches Portfolio mit Startseite, Lebenslauf, Projektvorstellung und Blog.

## Ziele

- HTML, CSS und responsives Design von Grund auf verstehen, nicht nur abtippen
- Zu jedem Thema eine kleine Übung mit Musterlösung nachvollziehen
- Am Ende eine schnelle, barrierefreie und datenschutzfreundliche Seite besitzen

## Aufbau

- 21 Module nach dem Lehrplan „Webdesign HTML CSS responsives Design“ (294,5 Stunden)
- Pro Unterkapitel eine Übung, pro Modul eine README mit Etappen-Abnahme
- Jede Übung: Lernziele, Voraussetzungen, Ausgangslage, Aufgabe, Hinweise, Lösung, Erweiterungen
- Der lauffähige Stand nach jedem Modul liegt im Ordner [`portfolio/`](portfolio/)
- Zu jedem Modul das zugehörige Kapitel des Skripts als `skript.md`; [Einleitung](docs/skript-einleitung.md) und [Quellenverzeichnis](docs/skript-quellenverzeichnis.md) stehen im Ordner `docs`
