# 04.4 Overflow

> Modul 04 · Lehrplan 4.5 · Geschätzter Zeitaufwand: 45 Minuten

## Lernziele

- Du steuerst Inhalt, der größer als seine Box ist (`visible`, `hidden`, `scroll`, `auto`, `clip`).
- Du findest die Ursache für ungewollten horizontalen Scrollbalken.

## Voraussetzungen

04.3

## Ausgangslage

Auf dem Handy kann ein zu breites Element die ganze Seite waagerecht scrollen lassen.

## Aufgabe

1. Setze auf der Kontaktseite einen langen Text ohne Leerzeichen ein (z. B. eine lange URL). Öffne die Seite bei 360 px Breite und beobachte den horizontalen Scrollbalken.
2. Behebe das Problem mit `overflow-wrap: anywhere` (Klasse `.umbruch`).
3. Kürze die Kurzbeschreibung einer Karte mit einer Zeile und Auslassungspunkten (`text-overflow: ellipsis`). Welche zwei weiteren Eigenschaften braucht es?
4. Nenne drei häufige Ursachen für ungewollten horizontalen Scroll auf Mobilgeräten.
5. Warum verhindert `overflow: hidden` im Elternelement ein `position: sticky` im Kindelement?

## Hinweise

- `overflow: hidden` erzeugt einen neuen Formatierungskontext. Ein Scrollcontainer ist außerdem der Bezugspunkt für `sticky`.
- Die DevTools helfen: Mit dem Element-Auswahlwerkzeug siehst du die Breite jedes Elements; ein Element, das über den Rand ragt, ist der Verursacher.

---

## Lösung

1. Eine lange Zeichenkette ohne Umbruchmöglichkeit ragt aus der Box und verbreitert die Seite.
2. ```css
.umbruch { overflow-wrap: anywhere; }
```
   Fertiger Stand: Kontaktseite in [`../portfolio/modul-04/kontakt/index.html`](../portfolio/modul-04/kontakt/index.html).
3. ```css
.kurz {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```
   `text-overflow: ellipsis` wirkt nur zusammen mit `white-space: nowrap` und `overflow: hidden`.
4. (a) feste `width` in Pixeln, (b) `width: 100vw` bei vertikalem Scrollbalken, (c) Bilder ohne `max-width: 100%`. Auch häufig: lange Wörter ohne Umbruch.
5. `overflow: hidden` macht das Elternelement zum Scrollcontainer. `sticky` bezieht sich dann auf diesen Container statt auf den Viewport und haftet nicht mehr am Bildschirmrand.

## Erweiterungen

- Lege eine breite Tabelle an und lasse sie mit `overflow-x: auto` in einem Wrapper scrollen (Modul 09 vertieft das).
