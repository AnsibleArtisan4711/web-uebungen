- [ ] Menü, Filter, Suche und Formular sind per Tastatur bedienbar
- [ ] Keine Fehler in der Konsole
- [ ] `npm test` läuft durch (6 Tests)
- [ ] `docs/js-review.md` ist ausgefüllt
