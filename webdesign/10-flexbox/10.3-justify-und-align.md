# 10.3 Justify und Align

> Modul 10 · Lehrplan 10.4 · Geschätzter Zeitaufwand: 75 Minuten

## Lernziele

- Du zentrierst Elemente horizontal und vertikal auf zwei Arten.
- Du baust eine Navigationsleiste mit Logo links und Links rechts.
- Du nutzt `margin: auto` an Flex Items, um Restplatz aufzunehmen.

## Voraussetzungen

10.2

## Ausgangslage

Der Kopf des Portfolios hat schon Logo links und Links rechts. Jetzt baust du die Leiste selbst von Null.

## Aufgabe

1. Zentriere ein Element horizontal und vertikal im Viewport (zwei Varianten): Flexbox und Grid. Vergleiche mit [`experimente/zentrieren.html`](../portfolio/modul-10/experimente/zentrieren.html).
2. Baue eine Leiste: Logo links, drei Links rechts, vertikal mittig ([`experimente/leiste.html`](../portfolio/modul-10/experimente/leiste.html) als Vorlage).
3. Warum benutzt das Portfolio `margin-inline-end: auto` statt `margin-right: auto`?
4. Nenne drei Werte von `justify-content` und beschreibe die Verteilung. Wann ist `space-between` sinnvoll, wann `space-evenly`?
5. Was bewirkt `align-items: stretch` (Standard) und wann siehst du es nicht?

## Hinweise

- `100svh` ist die kleine Viewport-Höhe (ohne die ausgeblendeten Browserleisten des Handys). `100vh` kann auf Mobilgeräten zu hoch sein.
- `margin: auto` an einem Flex Item verbraucht den restlichen Platz auf dieser Seite, bevor `justify-content` wirkt.
- Stretch streckt die Items auf die Höhe des Containers (der Querachse), nicht auf die Breite.

---

## Lösung

1. ```css
.zentriert { display: flex; justify-content: center; align-items: center; min-height: 100svh; }
/* Variante B */
.zentriert { display: grid; place-items: center; min-height: 100svh; }
```
   Gemessen: Der Mittelpunkt des Kastens liegt in beiden Varianten exakt im Mittelpunkt des Containers (Abweichung 0 px).
2. ```css
.leiste { display: flex; align-items: center; gap: 1rem; }
.leiste .logo { margin-inline-end: auto; }
```
   Gemessen: Das Logo steht links (x = 32 px), die drei Links rechts bündig am Containerrand (x = 703, 730, 756 px).
3. Logische Eigenschaften drehen sich bei Schrift von rechts nach links mit. `margin-right` bliebe rechts, auch wenn die Seite gespiegelt wird (Modul 07).
4. `flex-start`: Items am Anfang. `center`: Items in der Mitte. `space-between`: erstes ganz links, letztes ganz rechts, gleiche Abstände dazwischen (gut für Kopfzeilen). `space-evenly`: überall gleiche Abstände, auch außen (gut für Symbolleisten).
5. `stretch` streckt Items quer zur Hauptachse auf die Höhe der höchsten Linie oder des Containers. Du siehst es nicht, wenn Items eine feste Höhe haben oder `align-items` einen anderen Wert hat.

## Erweiterungen
