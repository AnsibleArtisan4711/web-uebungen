# 01.8 CSS: Zweck, Syntax und Einbindung

> Modul 01 · Lehrplan 1.9 · Geschätzter Zeitaufwand: 45 Minuten

## Lernziele

- Du schreibst CSS-Regeln aus Selektor, Property und Wert.
- Du kennst die drei Einbindungsarten und wählst für große Projekte die richtige.

## Voraussetzungen

01.6, 01.7

## Ausgangslage

Deine Seite besteht aus ungestaltetem HTML.

## Aufgabe

1. Lege `css/main.css` an und binde sie mit `<link rel="stylesheet" href="css/main.css">` in den `<head>` von `index.html` ein.
2. Schreibe Regeln für:
   - `body`: Systemschrift, Schriftgröße `1rem`, Zeilenhöhe `1.5`, maximale Breite `40rem`, zentriert, innen etwas Abstand, dunkelgraue Schrift auf weißem Grund.
   - `h1` und `h2`: Farbe `#1a3c6e`.
   - `img`: `max-width: 100%` und `height: auto`.
3. Öffne [`experimente/einbindung.html`](../portfolio/modul-01/experimente/einbindung.html). Sie bindet dieselbe Farbe auf drei Arten ein (extern, intern, inline). Welche Regel gewinnt bei der Überschrift, welche beim Absatz? Prüfe es in den DevTools unter *Styles* (durchgestrichene Regeln sind unterlegen).
4. Begründe: Welche Einbindungsart nimmst du für das Portfolio und warum? Warum ist `@import` in CSS keine gute Wahl?

## Hinweise

- Eine Regel besteht aus Selektor und Deklarationsblock. Jede Deklaration heißt `property: wert;`.
- Relative Einheiten wie `rem` skalieren mit der Schrifteinstellung der Nutzenden. Das ist besser für Barrierefreiheit als feste Pixelwerte.
- Die Reihenfolge der Auswertung (Cascade, Specificity) ist Thema von Modul 03. Hier genügt die Beobachtung.

---

## Lösung

Schritt 1 und 2, Datei `css/main.css`:

```css
/* Portfolio, Modul 01: erstes externes Stylesheet */

body {
  font-family: system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.5;
  max-width: 40rem;
  margin: 2rem auto;
  padding: 0 1rem;
  color: #1a1a1a;
  background: #ffffff;
}

h1,
h2 {
  color: #1a3c6e;
}

img {
  max-width: 100%;
  height: auto;
}
```

Im `<head>`:

```html
<link rel="stylesheet" href="css/main.css">
```

3. Der **Inline-Style** gewinnt beim Absatz. Bei der Überschrift gewinnt die interne Regel (`darkgreen`) über die externe, weil sie **später** im Dokument steht und beide dieselbe Spezifität haben.
4. Für das Portfolio: ein **externes Stylesheet**. Es wird gecacht, ist zentral wartbar und trennt Struktur von Darstellung. Inline-Styles sind schwer zu überschreiben und nicht wiederverwendbar. `@import` lädt Dateien nacheinander und verzögert das Rendering; besser sind mehrere `<link>`-Tags oder ein Build-Schritt.
