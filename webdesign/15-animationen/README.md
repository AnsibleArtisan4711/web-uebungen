## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] Übergänge nennen ihre Eigenschaften (kein `transition: all`)
- [ ] Hover-Effekte stehen in `@media (hover: hover)`, Fokus bekommt dasselbe Feedback
- [ ] Es werden nur `transform` und `opacity` animiert
- [ ] `prefers-reduced-motion: reduce` wurde geprüft
- [ ] Endlosanimationen sind pausierbar
- [ ] `docs/interaction-qa.md` ist ausgefüllt
