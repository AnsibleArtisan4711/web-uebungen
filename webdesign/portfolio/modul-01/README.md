# Portfolio: Stand nach Modul 01

Statische Beispielseite für die Webdesign-Kursreihe. Enthält nur Platzhalterinhalte, keine persönlichen Daten.

## Ansehen

`index.html` im Browser öffnen (Doppelklick genügt, es wird kein Server benötigt).

## Struktur

```
modul-01/
  index.html          Startseite
  css/main.css        Stylesheet
  img/                Avatar (PNG und SVG-Quelle)
  docs/               Briefing, Personas, Rollen, Projektplan, Qualitätskriterien
  experimente/        Kleine Testseiten zu den Übungen 01.6 bis 01.8
```

## Hinweise

- Das Avatarbild ist eine gezeichnete Grafik (35 x 45 mm bei 300 dpi, 413 x 531 px), kein Foto.
- Namen in `docs/personas.md` sind erfundene Beispiele.
- Keine Build-Schritte, keine Abhängigkeiten.
