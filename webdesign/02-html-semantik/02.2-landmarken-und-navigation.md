# 02.2 Landmarken und Navigation

> Modul 02 · Lehrplan 2.3 · Geschätzter Zeitaufwand: 45 Minuten

## Lernziele

- Du kennst die impliziten Rollen der Landmark-Elemente.
- Du baust eine Navigation als Liste, markierst die aktuelle Seite und ergänzt einen Skip-Link.

## Voraussetzungen

02.1

## Ausgangslage

Die Startseite hat eine einfache Navigation, es gibt aber nur diese eine Seite.

## Aufgabe

1. Lege die weiteren Seiten als Ordner mit `index.html` an: `lebenslauf/`, `projekte/`, `blog/`, `kontakt/`. Kopiere das Seitengerüst und passe `title` und `h1` an.
2. Baue die Navigation als `nav` mit `ul` und `li` auf allen Seiten gleich. Kennzeichne die jeweils aktuelle Seite mit `aria-current="page"`.
3. Ergänze ganz am Anfang des `body` einen Skip-Link (`Zum Inhalt springen`) auf `#inhalt`.
4. Ordne zu: Welche implizite Landmark-Rolle haben `header`, `nav`, `main`, `aside`, `footer`? Wann sind `header` und `footer` *keine* Landmarken?
5. Teste mit der Tab-Taste: Zu welchem Element springt der Fokus zuerst? Was passiert bei Enter?

## Hinweise

- Gibt es mehrere `nav`-Elemente, bekommt jedes ein eigenes `aria-label` (z. B. „Hauptnavigation“, „Fußnavigation“). Bei einem einzigen genügt ein einfacher Name.
- Verwende `href="lebenslauf/index.html"` mit ausgeschriebenem `index.html`. Beim Öffnen per Doppelklick (`file://`) funktionieren Ordner-Links ohne Dateinamen nicht. Mit einem Server (Modul 19) wären `/lebenslauf/` die sprechenden URLs.
- Seiten in Unterordnern brauchen `../` in den Pfaden zu CSS, Bildern und anderen Seiten.

---

## Lösung

1. und 2. Struktur siehe [`../portfolio/modul-02/`](../portfolio/modul-02/). Navigation einer Unterseite:

```html
<nav aria-label="Hauptnavigation">
  <ul>
    <li><a href="../index.html">Start</a></li>
    <li><a href="../lebenslauf/index.html" aria-current="page">Lebenslauf</a></li>
    <li><a href="../projekte/index.html">Projekte</a></li>
    <li><a href="../blog/index.html">Blog</a></li>
    <li><a href="../kontakt/index.html">Kontakt</a></li>
  </ul>
</nav>
```

3. Skip-Link, erstes Element im `body`:

```html
<a class="skip-link" href="#inhalt">Zum Inhalt springen</a>
```

Das Gegenstück ist `<main id="inhalt">`. Das CSS blendet ihn aus, bis er per Tastatur Fokus bekommt (siehe `css/main.css`, Details in Modul 14).

4. `header` → banner, `nav` → navigation, `main` → main, `aside` → complementary, `footer` → contentinfo. `header` und `footer` sind nur dann Landmarken, wenn sie direkt im `body` liegen; innerhalb von `article` oder `section` nicht.
5. Der erste Tab-Stopp ist der Skip-Link (er wird sichtbar). Enter springt zum Hauptinhalt und überspringt die Navigation.
