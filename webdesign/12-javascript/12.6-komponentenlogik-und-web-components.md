# 12.6 Komponentenlogik und Web Components

> Modul 12 · Lehrplan 12.7 · Geschätzter Zeitaufwand: 90 Minuten

## Lernziele

- Du kapselst Verhalten in kleine Komponenten (Zustand in Attributen, Initialisierung per `querySelectorAll`).
- Du prüfst zuerst native Lösungen (`<details>`).
- Du schreibst ein einfaches Custom Element mit Shadow DOM.

## Voraussetzungen

12.3, 12.4

## Ausgangslage

Die Kontaktseite braucht einen FAQ-Bereich, und das Portfolio ein wiederverwendbares Badge.

## Aufgabe

1. Sieh dir den FAQ-Bereich in [`kontakt/index.html`](../portfolio/modul-12/kontakt/index.html) an. Er nutzt `<details name="faq">`. Teste: Was passiert, wenn du die zweite Frage öffnest?
2. Warum ist das besser als ein eigenes Accordion mit `aria-expanded` und `hidden`? Nenne zwei Gründe.
3. Öffne [`experimente/web-component.html`](../portfolio/modul-12/experimente/web-component.html). Welche drei Badges siehst du, und wie unterscheiden sie sich?
4. Was bewirkt der Shadow DOM, und was macht `<slot>`?
5. Warum muss der Name `mein-badge` einen Bindestrich enthalten?

## Hinweise

- `name` bei `details` bildet eine exklusive Gruppe: nur ein Element ist geöffnet.
- Custom Elements haben einen Lebenszyklus (`connectedCallback`, `attributeChangedCallback`).
- Vor dem `define` ist das Element „nicht definiert“: `:not(:defined)` erlaubt einen Fallback.

---

## Lösung

1. Gemessen: Nach dem Öffnen der ersten und danach der zweiten Frage ist nur die zweite offen (`open` ist beim ersten `false`, beim zweiten `true`).
2. Native Elemente sind ohne Code bedienbar (Tastatur, Screenreader-Rolle und -Zustand, Suche in der Seite), brauchen kein JavaScript und funktionieren auch, wenn das Skript ausfällt.
3. Blau („Neu“, `rgb(26, 60, 110)`), rot („Wichtig“, `rgb(176, 0, 32)`) und grau als Standard (`rgb(85, 85, 85)`). Die Farbe kommt aus dem Attribut `farbe`, gesetzt als CSS-Variable.
4. Shadow DOM kapselt Markup und Stile: Seitenstile wirken nicht hinein, die Komponente stört die Seite nicht. `<slot>` ist die Stelle, an der der Inhalt zwischen den Tags erscheint („Neu“).
5. So können Browser eigene Elemente (die nie einen Bindestrich haben) von Custom Elements unterscheiden.

   Hinweis: Das Skript des Experiments läuft im Dokument; im Portfolio gehört so etwas in eine eigene Datei mit `defer`.
