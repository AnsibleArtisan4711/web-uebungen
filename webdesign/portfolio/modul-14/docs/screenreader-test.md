# Screenreader-Kurztest (NVDA, Windows)

NVDA ist kostenlos (nvaccess.org). Dieser Test wurde in der Entwicklung **nicht** durchgeführt, weil dafür ein echter Screenreader nötig ist. Trage deine Beobachtungen ein.

Vorbereitung: NVDA starten, Firefox oder Chrome öffnen, Seite laden. Mit Strg stoppst du die Sprachausgabe.

| Aufgabe | Taste in NVDA | Erwartung | Beobachtung |
|---|---|---|---|
| Seitentitel hören | Insert+T | „Portfolio AnsibleArtisan4711 …“ | |
| Überschriften durchgehen | H | Reihenfolge h1, h2 … ohne Sprünge | |
| Landmarken durchgehen | D | Banner, Navigation, Main, Contentinfo | |
| Navigation: aktuelle Seite | Tab | „aktuelle Seite“ beim aktiven Link | |
| Menü-Button (nur 360 px) | Enter | „Menü, eingeklappt/ausgeklappt“ | |
| Projektfilter | Tab, Leertaste | „Webdesign, Umschaltfläche, gedrückt“, danach „2 von 3 Projekten angezeigt“ | |
| Formular ausfüllen | F oder Tab | Jedes Feld mit Label, Hinweise werden mitgelesen | |
| Formular absenden ohne Eingabe | Enter | Fehlerliste wird vorgelesen, Fokus liegt darauf | |
| Dialog (Experiment) | Enter | Titel „Hinweis“ wird gelesen, Escape schließt | |
| Bilder | G | Avatar mit Alternativtext, dekorative Bilder werden übersprungen | |

Nicht geprüft werden konnte außerdem: JAWS, VoiceOver, TalkBack.
