## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] Blog und Lebenslauf nutzen `grid-template-areas` mit `minmax(0, 1fr)`
- [ ] Die Quelltextreihenfolge entspricht der sichtbaren Reihenfolge
- [ ] Kein horizontales Scrollen auf allen Seiten bei 320 bis 1280 px
- [ ] Die Fußzeile bleibt auch bei kurzem Inhalt unten
- [ ] `docs/grid-review.md` ist ausgefüllt
- [ ] Du kannst Grid und Flexbox begründet auswählen
