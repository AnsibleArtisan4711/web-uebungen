# 07.1 Mobile First und Viewport

> Modul 07 · Lehrplan 7.2 · Geschätzter Zeitaufwand: 45 Minuten

## Lernziele

- Du setzt die Viewport-Meta-Angabe und weißt, was ohne sie passiert.
- Du erklärst Mobile First: Basis-CSS für das kleinste Gerät, größere Viewports ergänzen.
- Du kennst die Gründe für Mobile First: Inhalt priorisieren, weniger Überschreiben, bessere Performance.

## Voraussetzungen

Modul 06 abgeschlossen

## Ausgangslage

Das Portfolio hat Layout-CSS, wurde aber bisher nur am Desktop angesehen.

## Aufgabe

1. Öffne [`experimente/ohne-viewport.html`](../portfolio/modul-07/experimente/ohne-viewport.html) in der Device Toolbar der DevTools (Strg+Umschalt+M, Gerät „iPhone“ oder ähnlich). Beobachte die Textgröße. Füge dann `<meta name="viewport" content="width=device-width, initial-scale=1">` in den `head` ein und vergleiche.
2. Warum rendern mobile Browser ohne diese Zeile eine „virtuelle“ Breite von etwa 980 px?
3. Warum ist `user-scalable=no` oder `maximum-scale=1` ein Zugänglichkeitsproblem?
4. Prüfe, dass alle Seiten des Portfolios die Viewport-Zeile haben.
5. Formuliere in zwei Sätzen den Unterschied zwischen Mobile First und Desktop First. Nenne drei Vorteile von Mobile First.

## Hinweise

- Mobile Browser kamen aus einer Zeit, in der Seiten nur für Desktop gebaut waren. Sie tun deshalb so, als wäre der Bildschirm etwa 980 px breit, und verkleinern das Ergebnis.
- Mobile First heißt: Das einfache Layout ohne Media Query gilt für alle, größere Bildschirme erhalten Ergänzungen per `min-width`.
- Im Portfolio hat jede Seite die Zeile schon seit Modul 01. Die Prüfung ist trotzdem sinnvoll (`grep`, DevTools oder `check.py`).

---

## Lösung

1. Ohne Zeile wird die Seite auf etwa 980 px virtueller Breite gerendert und auf Handybreite verkleinert, der Text ist winzig. Mit Zeile gilt die echte Gerätebreite und der Text ist lesbar.
2. Aus Kompatibilität mit Seiten aus der Desktop-Zeit.
3. `user-scalable=no` verhindert das Zoomen. Menschen mit Sehschwäche sind darauf angewiesen. WCAG 1.4.4 verlangt Vergrößerbarkeit auf 200 %.
4. ```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```
   Im Portfolio ist sie auf allen Seiten vorhanden (`check.py` meldet keine Probleme).
5. Mobile First: Das Basis-CSS gilt für das kleinste Gerät, größere Geräte erweitern. Desktop First: Das Layout gilt für Desktop und wird für kleine Geräte zurückgebaut. Vorteile: Inhalte werden priorisiert, es muss weniger überschrieben werden, Handys laden weniger CSS, das sie nicht brauchen.

## Erweiterungen

- Schaue dir die Option `viewport-fit=cover` und die `env(safe-area-inset-*)`-Werte für Geräte mit Aussparung (Notch) an.
