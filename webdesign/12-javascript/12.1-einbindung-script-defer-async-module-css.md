# 12.1 Einbindung: Script, defer, async, Module, CSS

> Modul 12 · Lehrplan 12.2 · Geschätzter Zeitaufwand: 60 Minuten

## Lernziele

- Du bindest CSS und JavaScript richtig ein und erklärst `defer`, `async` und `type="module"`.
- Du weißt, warum ein klassisches Skript den Parser blockiert.
- Du erkennst, wann ein Server nötig ist (Module, `fetch`).

## Voraussetzungen

Modul 11 abgeschlossen

## Ausgangslage

Dein Portfolio läuft bisher ohne JavaScript. Jetzt kommt das erste Skript dazu.

## Aufgabe

1. Lege `js/main.js` an und binde es im `<head>` mit `defer` ein (siehe [`index.html`](../portfolio/modul-12/index.html)).
2. Erkläre den Unterschied zwischen Skript ohne Attribut, mit `defer` und mit `async`. Wann nimmst du welches?
3. Starte im Ordner `modul-12` einen lokalen Server (`python3 -m http.server 8000`, unter Windows `py -m http.server 8000`) und öffne [`experimente/modul.html`](../portfolio/modul-12/experimente/modul.html) über `http://localhost:8000/experimente/modul.html`. Öffne dieselbe Datei danach per Doppelklick. Was siehst du jeweils, und warum?
4. Warum steht `<script>document.documentElement.classList.add("js")</script>` ohne `defer` im Kopf?

## Hinweise

- `defer`-Skripte laufen nach dem Parsen, in Quelltextreihenfolge, vor `DOMContentLoaded`.
- `async` ist nur für Skripte, die weder voneinander noch vom DOM abhängen.
- ES-Module lädt der Browser per CORS-Anfrage. Unter `file://` ist das blockiert.

---

## Lösung

1. ```html
<script src="js/logik.js" defer></script>
<script src="js/main.js" defer></script>
```
2. Gemessen (Chromium, Server mit künstlicher Verzögerung: Skript A 300 ms, Skript B 10 ms, A steht im Quelltext zuerst):

   | Variante | Ausführungsreihenfolge |
   |---|---|
   | ohne Attribut | A, B, dann `DOMContentLoaded` (`readyState` bei A: `loading`, der Parser hat gewartet) |
   | `defer` | A, B, dann `DOMContentLoaded` (`readyState` `interactive`) |
   | `async` | `DOMContentLoaded`, dann B, dann A (die Reihenfolge hängt vom Download ab) |

   Eigene Skripte bekommen `defer`. `async` passt für Unabhängiges wie Statistik.
3. Über `http://localhost:8000` steht „Hallo, AnsibleArtisan4711!“. Per Doppelklick bleibt der Text „Das Modul wurde nicht geladen.“, und die Konsole meldet einen CORS-Fehler. Module (und später `fetch`) brauchen http(s).
4. Das Snippet setzt die Klasse `js` sofort, noch vor dem ersten Zeichnen. So kann das CSS Elemente nur dann ausblenden, wenn JavaScript tatsächlich läuft (Übung 12.7). Mit `defer` käme die Klasse zu spät, es gäbe ein Aufblitzen des Layouts.
