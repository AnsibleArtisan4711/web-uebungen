# 05.5 Komponenten und Designsystem-Grundlagen

> Modul 05 · Lehrplan 5.6 · Geschätzter Zeitaufwand: 60 Minuten

## Lernziele

- Du baust Komponenten mit Varianten und Zuständen auf Basis von Tokens.
- Du kennst die Bestandteile eines Designsystems.

## Voraussetzungen

05.4

## Ausgangslage

Es gibt Buttons als Browser-Standard und Karten mit einzeln gesetzten Eigenschaften.

## Aufgabe

1. Schreibe eine **Button-Komponente** `.btn` mit Varianten (primär, `.btn--secondary`) und Zuständen (`:hover`, `:focus-visible`, `:disabled`). Nutze nur Tokens. Mindesthöhe `2.75rem` für eine große Klickfläche.
2. Setze den Button im Portfolio ein: Link „E-Mail schreiben“ auf der Kontaktseite und „Alle Projekte ansehen“ als Sekundär-Button auf der Startseite.
3. Warum nutzt du für den Hover `color-mix()` mit dem Text-Token statt eines zweiten festen Farbwerts?
4. Lege die Seite `styleguide/index.html` an und zeige Farben, Typografie, Buttons und eine Karte. Prüfe sie im hellen und dunklen Modus.
5. Beschreibe die fünf Bestandteile eines Designsystems (Tokens, Komponenten, Muster, Richtlinien, Governance) in je einem Satz für dein Portfolio.
6. Erkläre den Unterschied zwischen einem `<button>` und einem `<a class="btn">`. Wann nimmst du welchen?

## Hinweise

- Eine Komponente hat definierte Struktur, Varianten und Zustände. Varianten werden über Modifier-Klassen (`.btn--secondary`) oder über lokale Custom Properties gesteuert.
- Ein Link navigiert, ein Button löst eine Aktion aus. Beide dürfen gleich aussehen, die Semantik bleibt unterschiedlich.

---

## Lösung

1. ```css
.btn {
  --btn-bg: var(--color-primary);
  --btn-fg: var(--color-on-primary);
  display: inline-flex;
  align-items: center;
  gap: var(--space-2);
  min-height: 2.75rem;
  padding: var(--space-2) var(--space-3);
  border: 2px solid var(--btn-bg);
  border-radius: var(--radius);
  background: var(--btn-bg);
  color: var(--btn-fg);
  font: inherit;
  cursor: pointer;
}
.btn:hover { background: color-mix(in oklch, var(--btn-bg), var(--color-text) 15%); }
.btn:focus-visible { outline: 3px solid var(--color-focus); outline-offset: 2px; }
.btn:disabled { opacity: .5; cursor: not-allowed; }
.btn--secondary { --btn-bg: transparent; --btn-fg: var(--color-primary); }
```
2. ```html
<a class="btn" href="mailto:kontakt@example.com">E-Mail schreiben</a>
<a class="btn btn--secondary" href="projekte/index.html">Alle Projekte ansehen</a>
```
3. `color-mix()` mit dem Text-Token dunkelt im hellen Modus ab und hellt im dunklen Modus auf, weil das Text-Token seine Farbe mit dem Theme wechselt. Ein fester Wert müsste für beide Modi doppelt gepflegt werden.
4. Siehe [`../portfolio/modul-05/styleguide/index.html`](../portfolio/modul-05/styleguide/index.html).
5. Tokens: Farben, Abstände, Schrift. Komponenten: Button, Karte, Navigation. Muster: Seitenaufbau mit Kopf, Inhalt, Fuß. Richtlinien: Kontrast, Barrierefreiheit, Schreibstil. Governance: Ich bin Alleinentscheider, Änderungen landen im Entscheidungsprotokoll.
6. `<button>` für Aktionen (Formular absenden, Menü öffnen), `<a>` für Navigation zu einer Adresse. Ein Link, der wie ein Button aussieht, bleibt ein Link (Enter-Taste, Kontextmenü „Link öffnen“).

Fertiger Stand: [`../portfolio/modul-05/css/main.css`](../portfolio/modul-05/css/main.css) und [`../portfolio/modul-05/styleguide/`](../portfolio/modul-05/styleguide/).
