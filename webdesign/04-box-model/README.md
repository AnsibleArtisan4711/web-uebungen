## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] `box-sizing: border-box` ist global gesetzt
- [ ] Die Seite hat bei 360 px und 1280 px keinen horizontalen Scrollbalken
- [ ] Seitenkopf haftet (`sticky`), Badge sitzt in der Kartenecke (`absolute`)
- [ ] Ebenen laufen über Custom Properties, kein `z-index: 9999`
- [ ] Die vier Experimente wurden vorhergesagt und anschließend gemessen
