# 15.1 Transitions und Interaktionsstates

> Modul 15 · Lehrplan 15.2 · Geschätzter Zeitaufwand: 60 Minuten

## Lernziele

- Du schreibst Transitions für einzelne Eigenschaften.
- Du gestaltest Hover und Fokus gleichwertig.
- Du schützt Hover-Effekte mit `@media (hover: hover)`.

## Voraussetzungen

Modul 14 abgeschlossen

## Ausgangslage

Buttons ändern bisher beim Hover nur die Farbe sprunghaft.

## Aufgabe

1. Öffne [`css/main.css`](../portfolio/modul-15/css/main.css) und suche den Abschnitt „Interaktionsstates und Bewegung“. Welche Eigenschaften überblendet `.btn`, und wie lange?
2. Warum schreibt man Eigenschaften einzeln statt `transition: all`?
3. Teste auf der Projekte-Seite: Fahre mit der Maus über einen Button und gehe danach mit der Tastatur darauf. Was passiert jeweils?
4. Wozu dient `@media (hover: hover)`? Was gilt auf einem Touch-Gerät?
5. Schreibe einen eigenen Button mit sanftem Übergang (0,2 s) für Hintergrund und Verschiebung. Der Zustand `:active` soll den Button zurücksetzen.

## Hinweise

- Hover ist nie die einzige Funktionsquelle (Touch hat keins).
- `transition` gehört in den Grundzustand, nicht in `:hover`, damit auch das Zurückgehen überblendet wird.

---

## Lösung

1. `transition: background-color 0.2s ease, border-color 0.2s ease, transform 0.2s ease`. Gemessen: `transition-property` ist `background-color, border-color, transform`, Dauer je `0.2s`.
2. `all` überblendet auch Eigenschaften, an die man nicht denkt (Layout-Werte), das ist unvorhersehbar und kann teuer sein. Eigenschaften zu benennen macht den Effekt klar.
3. Gemessen: Beim Hover und beim Tastaturfokus (`:focus-visible`) ist `transform` jeweils `matrix(1, 0, 0, 1, 0, -2)`, der Button hebt sich um 2 px. Tastaturnutzer bekommen dasselbe Feedback wie Mausnutzer.
4. Es greift nur auf Geräten mit echtem Hover. Gemessen: Auf einem emulierten Touch-Gerät ist `(hover: hover)` falsch, die Hover-Verschiebung greift dort nicht. Auf Touch bleibt ein Hover-Effekt sonst nach dem Tippen „kleben“.
5. ```css
.knopf { background: #1a3c6e; transition: background-color .2s ease, transform .2s ease; }
@media (hover: hover) { .knopf:hover { background: #24539a; transform: translateY(-2px); } }
.knopf:focus-visible { background: #24539a; transform: translateY(-2px); }
.knopf:active { transform: translateY(0); }
```
