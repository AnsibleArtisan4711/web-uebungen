## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] `index.html` ist valide (W3C Validator ohne Fehler)
- [ ] `document.compatMode` ergibt `"CSS1Compat"`
- [ ] Das Stylesheet ist extern eingebunden, das Bild hat `alt`, `width` und `height`
- [ ] Die Seite ist bei 360 px Breite ohne waagerechtes Scrollen lesbar
- [ ] `docs/` enthält Rollen, Projektplan, Personas, Briefing und Qualitätskriterien
- [ ] Lighthouse-Ausgangswerte sind notiert
- [ ] Keine echten persönlichen Daten im Ordner
