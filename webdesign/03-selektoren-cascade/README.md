## Etappen-Abnahme

Das Modul ist abgeschlossen, wenn Folgendes zutrifft:

- [ ] Alle Regeln liegen in einem der vier Layer `reset`, `base`, `components`, `utilities`
- [ ] Keine IDs im CSS und kein `!important`
- [ ] Links haben Hover und sichtbaren `:focus-visible`
- [ ] Externe Links erhalten per `::after` einen Pfeil
- [ ] Die Specificity-Experimente sind bewusst vorhergesagt und anschließend geprüft
